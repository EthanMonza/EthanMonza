## 🚀 Featured Projects

### [KiwiManga](https://github.com/EthanMonza/KiwiManga)
Async Rust Telegram bot (teloxide + tokio) that downloads manga / ranobe, packs them into CBZ / ZIP / EPUB, and sends them straight to chat.

SQLite WAL job queue with N workers, per-source token-bucket rate limiter, and graceful shutdown that survives `kill -9`. Ships with 16+ locales — including te reo Māori and proper Kiwi English — in a cargo-chef multi-stage Docker build.

`Rust` `teloxide` `sqlx` `tokio` `Docker`

### [kiwismir](https://github.com/EthanMonza/kiwismir)
Go Telegram bot (telebot v3) for pulling media from YouTube, TikTok, Instagram, Pinterest, Twitter/X, plus Spotify-to-MP3 resolution.

Built on yt-dlp + ffmpeg with Cobalt API support and `go:embed`’d 7 locales. Docker-ready, with a quality picker that tells you straight up when a quality isn’t available.

`Go` `telebot` `yt-dlp` `ffmpeg` `Docker`
